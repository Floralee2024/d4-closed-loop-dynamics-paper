# 合成瓶颈任务中的监督准则选择与留出效用

**稿件状态：**研究论文草稿，2026年10月26日

**作者：**Flora Lee（唯一作者）

**单位：**独立研究者与软件开发者（无机构隶属）

## 摘要

测量研究可以显示内部读数与任务分数同步变化，但无法据此确认改变训练目标是否会改变任务表现。本文报告一项独立的监督式干预研究，沿用 D4b 的逐控制条件重新训练协议。在每个控制参数值和残差强度条件下，我们重新训练符号瓶颈模型，并比较不增加准则损失与若干准则权重方案。主要比较使用 40 个相互独立的基础随机种子，并考察隐藏的 OOD 反转任务效用。一个仅使用验证数据的选择器为每个种子选出一组可执行的三项权重，并将其复用于各目标条件。所选处理组 joint_oracle_filtered 的归一化效用平均比零附加准则损失组 joint_none 高 0.005711。根据存档的种子级配对差值重新计算得到双侧 Student t 区间 [0.001736, 0.009687]；40 个种子中有 28 个差值为正。存档机器记录报告 PASS，决策字段为 NO_RL_PILOT_PASSED_RL_MAY_BE_PLANNED。内部读数并未都随效用上升：有效秩平均变化为 -0.016888，独立 q 空间时域探针变化为 +0.000681。这些结果支持这样一项结论：在该合成留出预测分数上，经过验证集选择的监督训练流程产生了效应。结果不能确定差异由哪一项准则成分造成，不能证明普遍的原则推理能力，也不能证明效果可迁移到自然语言模型或现实任务。

## 1. 引言

此前的 D4 研究比较了表征、时间关联和任务效用的操作性标记。D4a 在每个种子和表征变体下训练一个模型，同时改变数据生成的控制参数。D4b 则在每个控制参数值、残差强度和瓶颈规模条件下重新训练模型。两项研究的测量指标、效用尺度、阈值算法和训练协议各不相同，因此得到的 q90 标记是依赖具体协议的汇总结果 [1]。在这些存档比较中，D4a 所选时间关联指标的 q90 标记比所选使用／秩指标更接近效用标记；在 D4b 原始网格中，非零残差条件与更大的标记间距相伴。这些是离散网格上的标记比较，并非对同一连续起点的估计。

后续曲线复核保留了历史测量，同时收窄了解释范围。复算结果与存档的 1,860 个标记全部一致；复核还发现了网格边界命中、再次跌破阈值的曲线，以及不可定义的标记。D4a 中，160 个效用标记有 140 个位于 C=0。因此，这些标记彼此接近，可能是因为它们共同落在边界值，而不代表能力同步出现。我们把 D4 结果作为提出另一问题的动机：在监督学习过程中主动选择并加入一种训练准则，是否会改变留出任务效用？

本研究是直接的监督式后续研究。它保留 D4b 按 C 逐条件重新训练的估计目标，并加入七组干预，比较不同附加训练准则及其选择来源。主要对比是验证集选出的准则组合与附加准则损失为零的对照组。该比较检验的是完整训练流程，而不是某个表征指标是否足以代表任务表现，也没有分离某一内部读数所介导的因果路径。代理目标及其与期望结果的关系，在机器学习安全研究中已有更广泛的讨论 [2]。

## 2. 实验卡与估计目标

**研究问题。**在固定的合成序列任务和 D4b 式逐 C 重新训练协议下，与不增加准则损失的常规任务训练相比，经过验证集选择的监督准则加权流程是否能提高 OOD 反转条件下的留出任务效用？

**干预。**在固定候选集合中，使用单一锚点条件下的验证效用选出一组包含三项权重的准则，然后在所有目标条件的监督训练中加入所选准则损失。

**主要结果。**运行程序定义的隐藏任务效用，即经多数类基线校正的动作分类准确率；该指标在正 C 条件和残差强度条件上取平均。

**独立统计单位。**基础随机种子。先对每个种子重复的目标条件取平均，再为该种子计算一项处理组配对差值。条件、样本、序列位置和拟合选择器的运行次数不视为独立实验单位。

**证据支持的推断。**在给定模型、任务、参数网格和实现条件下，完整的“验证集选择＋监督训练”流程对指定合成留出分数的效应。

**尚未证实。**效应由秩或动态代理指标所介导的机制；普遍的原则推理能力；动作条件控制能力；现实世界或语言模型任务表现；或冻结模型权重、只干预前向路径所产生的效应。

## 3. 方法

### 3.1 合成任务与训练协议

实验使用 D4b 代码中的离散符号瓶颈模型和残差旁路模型族。正式运行使用 K=8 个符号、32 维观测、64 维隐藏层、12 维嵌入和原始模型变体。序列长度为 8。每个处理组、基础随机种子、C 值和残差强度条件都从头训练一个新模型。因此，估计目标是各条件训练流程下的重新训练结果，而不是冻结权重后的干预效应。

训练网格包含 C∈{0, 1, 3, 8} 和残差强度∈{0, 0.5, 1}。主要效用汇总排除 C=0，并在每个基础随机种子内对三个正 C 值和三种残差强度取平均。C=0 仍保留在发布的诊断曲线中。主要评估拆分为 ood_inverted；训练和验证使用混合合成分布。隐藏拆分不参与模型拟合或准则选择。正式运行包含 40 个基础随机种子（20 至 59），每个条件训练 60 步，批量大小为 128，每个条件各使用 512 条训练序列和验证序列。优化器为 AdamW，学习率为 0.002，权重衰减为 0.0001。

效用定义为归一化的超出多数类基线的动作预测准确率：

\[
U = \frac{A - A_{majority}}{1-A_{majority}},
\]

其中 A 是动作标签准确率，A_majority 是评估数据中多数动作类别的准确率。这是合成任务上的留出预测分数，不是交互环境中的单回合回报。

### 3.2 处理组与训练准则

基线监督目标包括动作预测、未来结果预测、符号使用与条件熵正则项，以及符号转移损失。附加准则项包括：(i) 潜在编码等价对比秩损失；(ii) 一项额外的未来结果预测损失；以及 (iii) 一项额外的动作预测损失。秩损失使用已知的合成潜在编码作为带有 oracle 辅助信息的结构目标。未来结果损失是对已观测目标的监督预测，不是在线转移干预。

七个处理组如下：

| 处理组 | 附加准则规则 |
|---|---|
| joint_none | 三项附加准则系数均为零；常规任务训练仍然进行。 |
| joint_default | 未筛选的默认权重：rank 0.20、dynamics 0.50、utility 0.50。 |
| joint_fixed | 固定的解析平衡权重：0.40、0.40、0.40。 |
| joint_self_unfiltered | 未经验证效用筛选而选出的方案。 |
| joint_oracle_filtered | 验证效用置信下界最大的候选方案。 |
| joint_misaligned | 使验证集秩与动态代理分数之和最大的候选方案。 |
| joint_random | 从同一固定候选集合中随机选择的方案。 |

附加损失为 L_add = w_rank L_rank + w_dynamics L_future + w_utility L_action。所有处理组都保留共同的监督目标。因此，joint_none 是附加损失为零的参照组，而不是不接受任务监督训练的模型。

每个候选方案从四组非负秩、动态和效用权重中选取：(0.40, 0.40, 0.40)、(0.60, 0.30, 0.30)、(0.30, 0.60, 0.30) 或 (0.30, 0.30, 0.60)。各候选方案的 L1 权重预算均为 1.20。每个基础随机种子只在一个锚点条件下选择验证筛选方案：K=8、残差强度 0.5、原始变体、C=3。候选选择器训练 12 步，进行两次选择器重复运行，并使用三个验证集副本。选择规则是最大化验证效用均值减去一个标准误。所选候选方案随后复用于该种子的所有目标条件。选择过程不使用隐藏拆分。

动态读数来自一个独立的 q 空间预测探针，用于预测一步和两步后的结果；探针在训练拆分上训练，并在各评估拆分上评分。它测量预测关联，不测量智能体的动作是否改变环境的未来状态。

### 3.3 统计分析

主要对比为 joint_oracle_filtered 减去 joint_none。先在每个种子内对 C∈{1, 3, 8} 和残差强度∈{0, 0.5, 1} 取平均，再对 40 个种子的配对差值进行汇总。报告的置信区间为双侧 95% Student t 区间，自由度为 39；该区间根据存档的种子级配对值 seed_level_effects.csv 重新计算。修订后的功效计划使用最小关注效应大小（SESOI）0.003 来确定样本种子数：估算需要 37 个，最终取整为 40 个。正式晋级门槛编码的是平均差为正（target_delta > 0），并未检验效应是否超过 SESOI。因此，存档中的 PASS 应按其实际编码的正效应规则解读；置信区间另行报告，作为种子级数据的透明汇总。

## 4. 结果

### 4.1 隐藏效用

验证筛选处理组相对 joint_none 的种子级效用平均差为 +0.005711（基础随机种子数 n=40；95% t 区间 [+0.001736, +0.009687]）。40 个种子中有 28 个差值为正。存档门槛记录报告 pilot_pass=true、hidden_utility_pass=true、anti_hacking_pass=true，决策字段为 NO_RL_PILOT_PASSED_RL_MAY_BE_PLANNED。点估计超过计划采用的 SESOI 0.003，但 95% 区间下界 +0.001736 未达到该数值；因此，数据不能以 95% 置信度证明效应至少为 0.003。记录还包含一个单独的全处理组逐行敏感性标记 no_proxy_only_risk，其值为 false（操作性代理指标下有 151 行，原始代理指标下有 90 行，其中目标处理组有 10 行原始代理指标记录）。该敏感性标记明确不属于晋级必需检查；目标组的聚合检查 target_no_systematic_proxy_only 则通过。PASS 不代表局部代理指标单独改善的情况完全不存在。

机器记录说明必需的晋级检查均已通过，同时也保留了上述未通过的逐行敏感性标记。这不意味着所有选定读数都改善了。目标组相对 joint_none 的归一化有效秩（erank_norm）平均差为 -0.016888，q 探针时域增益平均差为 +0.000681。因此，效用上升的同时，平均归一化有效秩读数下降，而预测动态读数的平均变化接近于零。现有证据不支持“干预改善了所有内部指标”的说法。

### 4.2 干预结果的解释

结果支持这样的判断：在该合成任务和评估拆分下，经过验证集选择的监督训练流程具有正向平均效应。主要处理同时包含候选方案训练、基于验证集的筛选、系数选择，以及最终目标条件训练中使用的附加损失。由于干预改变了多个相关环节，本研究无法将效用差异归因于秩、动态或效用损失中的某一项。处理组名称中的 oracle 指预先定义的验证集选择规则，不代表使用了隐藏测试数据，也不代表模型具有普遍推理能力。

## 5. 讨论

本研究将 D4 研究计划从比较测量指标推进到改变训练流程。主要发现是：在所述监督式合成设置中，从一个规模较小、可执行的准则候选集合中通过验证集选择方案后，留出任务预测分数出现了小幅正向平均变化。这是训练流程层面的干预结果，并不说明指标改善本身会导致效用上升。事实上，秩代理指标的平均值下降，而任务分数上升。

有三项设计选择界定了本研究的范围。第一，对照组的附加秩、动态和效用准则损失确实为零，同时仍保留任务本身的常规监督损失。第二，选择决策只在一个验证锚点上作出，并复用于所有目标条件。第三，效用在一个未用于选择的反转伪特征拆分上评估。这些选择界定了流程层面的对比，但其内部作用路径仍未解析。

本研究仍有若干局限。效用是归一化分类分数，不是闭环智能体获得的奖励。环境、标签、数据分布和模型均为合成构造。候选集合较小且由研究者手工指定。秩准则使用了合成潜在编码标签。结果不能证明自然语言模型能够表征或推理普遍原则。最后，在每个 C 和残差条件下重新训练，回答的问题不同于冻结权重、只改变前向路径成分的研究。

最可能改变当前解释的下一项测试，是将选择过程与准则内容分开：在预先声明主要效用对比并增加留出种子的设计中，将相同的已选系数与匹配的未筛选及错位系数进行比较。若要测试表征读数变化是否介导效用结果，则还需要单独开展固定模型研究。
